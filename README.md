## 📖 The Story Behind Valence

**VALENCE Studio** is an international creative direction and digital design practice operating at the intersection of haute couture, computational design, and architectural typography. Rejecting generic corporate templates, VALENCE champions a raw brutalist aesthetic: high-contrast obsidian canvases, fine hairline grids, typographic hierarchies, and fluid case-study storytelling.

This web application serves as the studio's living archive, spotlighting award-winning campaigns across Paris, Tokyo, and New York.

---

## ✨ Key Functions & Experience

### 1. Deep-Dive Case Study Inspection Drawer
- **Full Case Study Breakdown**: Interactive slide-out panels detailing the Challenge, Strategic Solution, Tech Architecture, and Art Direction for each client.
- **Multi-Image Lightbox Gallery**: High-resolution editorial spreads and interaction captures.

### 2. Multi-Disciplinary Category Filter
- Instant sorting across **FASHION**, **ARCHITECTURE**, **DIGITAL**, **EDITORIAL**, and **COMMERCE**.
- Dynamic grid animation with zero layout flickering.

### 3. Ambient Audio Atmosphere Synthesizer
- Integrated generative ambient drone audio with instant mute/unmute controls in the sticky navigation header.

### 4. Real-Time Global Studio Clocks
- Live synchronized world clocks tracking time in Paris (CET), New York (EST), and Tokyo (JST).

### 5. Interactive Commission Inquiry
- Form drawer with budget tier selection, project timelines, and real-time form validation.

## 🛠️ Technology Stack

- **Framework**: Next.js 16
- **Library**: React 19
- **Styling**: Tailwind CSS + Brutalist Obsidian Palette (`#0a0a0a` & `#ffffff`)
- **Animation**: Framer Motion
- **Icons**: Lucide Icons

## 🚀 Quick Start & Local Development

```bash
# Clone the repository
git clone https://github.com/orivojka-eng/valence.git

# Navigate to directory
cd valence

# Install dependencies
npm install --legacy-peer-deps

# Start development server
npm run dev
```
